# Client — Frontend del Portafolio

Frontend en React 19 + Vite + Tailwind CSS 4 + Framer Motion.

Consulta el [README raiz](../README.md) para la documentacion completa (setup, variables de entorno y estructura del proyecto).

## Comandos rapidos

```bash
npm install
npm run dev      # desarrollo (http://localhost:5173)
npm run build    # build de produccion
npm run lint     # ESLint
```
